# weekly review

Read visit-plan, scorecard, repeat-failures and attention. Present missed visits first, then critical failures, repeat problems and named action owners.

Use this shape and substitute the operator's values:

```bash
npm run audit -- weekly-review
```

For fields and constraints, read docs/cli.md. Use --json for analysis. Keep private records and generated reports out of Git.
