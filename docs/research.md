# Target research: GoAudits

Sources reopened 1 November 2026.

The selected family is retail standards audits: regional store visits, checklist observations, repeat presentation failures, evidence review and corrective work. Internal financial audits and manufacturing quality already exist in the rebuild registry. This project does not cover those wider disciplines.

Annual scenario: $18,000 for 50 Enterprise users at the displayed $30 per user per month, billed annually. This is arithmetic from a tariff, not a customer invoice. The pricing page uses a dollar symbol without establishing currency. Confirm the invoice currency, taxes and any volume discount with GoAudits. Never describe this as verified NZ or AU spending.

Scores in order: annual bill 2, data-shaped 5, buyer fit 2, search demand 2, one-session buildable 5, import path 4. Total 20/30. No measured keyword volumes or verified GoAudits purchase by an Enterprise DNA customer. Existing local delivery notes show inspection-form needs only; they do not establish vendor use. The public retail page lists an Australia office. Search intent is qualitative.

The rejected shortlist: VWO 1/4/2/3/3/4 = 17, with no current public five-figure tariff and a broader experiment delivery engine. Juniper Square 1/5/2/2/4/3 = 17, with no public current price and overlap with the existing unit registry. No spend-analysis family was selected.

Sources:

- [GoAudits pricing](https://goaudits.com/pricing/): displayed Starter 10 and Enterprise 30 per user/month under annual billing. Enterprise adds scheduling, permissions and advanced reporting. No claim that reporting or exports are absent from GoAudits.
- [GoAudits retail](https://goaudits.com/retail/): store audits and operational standards.
- [GoAudits API documentation](https://api.goaudits.com/), with its [public endpoint descriptions](https://api.goaudits.com/apiModules.json): auditDetails rows, audit ids, client/location ids, question numbers, answers, scores and comments. Export Audit Details documents an EXCEL file type. See the replacement guide for the exact supported interchange.
- [VWO pricing](https://vwo.com/pricing/): current tiers require contact.
- [Juniper Square](https://www.junipersquare.com/): broader investment management product.

GoAudits offers mobile and offline collection, photos, notifications, conditional questions and other services beyond these records. This base covers a fixed checklist and review workflow. It never sends an email, fetches a private photo or certifies compliance. Scope custom mobile collection and existing-system connections with Enterprise DNA before switching a field team.
